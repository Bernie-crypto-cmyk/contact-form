# contact-form

**Description**
This is a fill in form where users should be able to: 

1. Complete the form and see a success toast message upon successful submission
2. Receive form validation messages if:
  - A required field has been missed
  - The email address is not formatted correctly
3. Complete the form only using their keyboard
4. Have inputs, error messages, and the success message announced on their screen reader
5. View the optimal layout for the interface depending on their device's screen size
6. See hover and focus states for all interactive elements on the page
